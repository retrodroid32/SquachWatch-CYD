## Candidate update after RSSI UX patch

The initial migration, Stage B Alert Rules, and Stage C Device Policy passes above
were completed against `lab-v121-hw` at
`fee5b2ae7ef412253499cdb0f59104570b8b256e`.

PR #30 then changed only RSSI presentation/classification behavior and was
merged as `dc452c8503a9c7e7d9dad8f4de22c128f46e59e3`. The patch:
- removes long-history trend/sparkline presentation from ALERT,
- keeps HUNT's playful GETTING WARMER / HOLDING STEADY / GETTING COLDER text,
- makes HUNT and LOG share the same 3-sample / +/-6 dB classifier,
- does not change migration, NVS, policies, WATCH semantics, alert gating,
  BlackBox/SD formats, Detection size, or HUNT catch behavior.

Therefore the already-passed migration/Stage B/Stage C checks do not need to be
repeated. The new lab candidate needs focused ALERT/HUNT/LOG RSSI retesting.
