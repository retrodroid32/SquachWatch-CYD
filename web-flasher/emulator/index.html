A SquachWatch nearby

A second SquachWatch that only exists in this page. It sends real SquachMesh adverts into the real firmware, so it turns up exactly when a board nearby would — and it answers what you send it.

On a real board SquachMesh starts behind a warning you have to accept, then a phrase you pick. Set up skips both — you can still walk through them yourself under Settings. Its look is copied once, when it arrives, just as a board does: to see a new outfit or name, send it away, let it leave, and bring it back.

Getting around

  • First boot runs a colour check and Squachy's walkthrough — tap through them.
  • SCAN LOG CLR along the bottom.
  • The gear in the top-left opens Settings; the icon top-right rotates the screen, and the board turns with it.
  • Tap Squachy to pet him. Hold CLR for four seconds to unlock every outfit.
  • On physical classic CYDs, BOOT toggles POCKET MODE. A BOOT control only appears here if the bundled WebAssembly build supports that input.
  • The board art, ruler and USB cable illustrate its size and layout. They are not measurements of the attached physical hardware.
  • Other upstream v1.41 boards require separately compiled, board-specific browser firmware and are not shown as active in this fork.
  • Use Fit for the available space, Same scale for repeatable comparisons, or Actual size for approximately physical monitor scale.

What's real and what isn't

Real in this bundle: the C++ state machine, screen rendering, touch mapping, settings and persistence from the bundled classic-CYD WebAssembly build. Panel brightness and BOOT handling only appear if that build exports them. The browser's canvas is derived from RGB565 framebuffer pixels.

Not real: the radios. Detections come from the Trigger button, the nearby SquachWatch is simulated, messages use a stand-in cipher rather than the device's AES, and the shape layer isn't pixel-exact against the display library.

This checkpoint ships only the classic CYD simulator. It does not download upstream's T-Deck, watch or Cardputer code, substitute CYD firmware into unsupported board drawings, or alter either physical CYD firmware target.

The 3.2-inch ST7798 will need its own verified browser display profile. This page does not present a 2.8-inch simulator as a tested 3.2-inch build.

The frame rate is capped to 33fps to match what the hardware actually manages once the SPI push to the panel is counted, so animations run at device speed rather than at your monitor's refresh.
